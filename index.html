Add New Lab

To add a new lab to this portal:

  1. Create a new folder with the lab number (e.g., "03")
  2. Add your lab files in the "code" subfolder
  3. Make sure you have an index.html in that folder
  4. Edit the labsData array in script.js
  5. Add a new object with lab details
{
  id: 3,
  title: "JavaScript Fundamentals",
  description: "Introduction to JavaScript programming",
  tasks: 4,
  difficulty: "Intermediate",
  color: "#9c27b0"
}
